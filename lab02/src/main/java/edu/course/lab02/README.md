# Инварианты модуля lab02 (Программная инженерия)

1. **Идентификация и текст:** Поля `id` и `title` объекта `ProjectTask` никогда не могут принимать значения `null` или содержать только пробелы/пустые строки.
2. **Времязатраты:** Поле `estimatedHours` не может быть отрицательным числом (`>= 0`). Увеличение трудоемкости возможно только на строго положительное число часов (`> 0`).
3. **Состояние:** Поле `status` контролируется строго через перечисление `TaskStatus` и не может быть переведено в состояние `null`.
